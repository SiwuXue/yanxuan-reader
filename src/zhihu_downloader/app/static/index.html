            THE PROJECT

            关于盐选书房

            版本 读取中…

            盐选书房（yanxuan-reader）—— 把知乎网页中可阅读的文章与盐选章节备份成 EPUB / TXT / Markdown，方便导入墨水屏阅读器。支持扫码登录、断点续传、 字体反爬解码与书架追更，全部数据只保存在这台电脑上。

            • 项目仓库 源码、更新日志与问题反馈
            • 作者博客 开发笔记与工具分享
            • 爱发电赞助 支持这个工具继续更新

            链接会在浏览器新标签页打开。下载的文件保存在这台电脑的 ~/.zhihu_downloader/output 目录。

            本工具只用于把你有权阅读的内容备份到自己的设备，数据不离开这台电脑。

            扫码登录知乎

            打开知乎 App → 点右上角「扫一扫」→ 扫描下面的二维码 → 在手机上确认。

            设置

            登录状态

              签名 Cookie（d_c0）缺失时无法下载，请重新扫码或手动导入。

              手动导入 Cookie

              扫码不方便时，可以从浏览器复制 Cookie 粘贴到这里。支持三种格式：

              • 原始串k1=v1; k2=v2
              • JSON 对象{"z_c0": "…"}
              • Netscapecookies.txt（7 列）

              退出登录

              删除本机保存的 Cookie，已下载的文件不受影响。

              确定要退出登录吗？之后需要重新扫码才能下载付费章节。
